# LEXI OS

<centre>A desktop envirinment which runs in your browser. </center>

- Features: 
  - Windowing System: Features multiple fully draggable, stackable windows which are designed to open only one Instance.
  - Dock: a macOS-style bottom dock with an open app indicator and smooth animations while opening the app
  - Top bar: displays the clock, the OS name and just icons of internet, battery and sound
    <img width="2499" height="1388" alt="image" src="https://github.com/user-attachments/assets/126d50c7-89fa-4722-a831-4ebec3e0b29e" />

  
- Design Elements:
   - Main focus of lexi os - Transparent Windows - key highlight which is integrated in all the apps
   - Glassmorphism - 2px blur and 180% saturation for all the apps
   - Boot sequence - OS name and logo reveal with sliding and a custom cinematic loader inspired by my Personal site
   - LexI color theme - Bright Cyan, dark blues and light greys for contrast
   - The apps icons are designed with the help of agent in Figma
   - Aesthetic elements - Features an Analogue clock and a digital clock along with a scrollable calender inspired from [MewoOS](https://github.com/subhansh-dev/MewoOS)
